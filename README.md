# Diabetic Prediction

Portfolio-friendly machine learning project structure.

## Structure

- `data/raw/` - original, untouched datasets
- `data/processed/` - cleaned and transformed data
- `data/external/` - third-party or reference datasets
- `notebooks/` - exploration and experimentation notebooks
- `src/data/` - data loading and preprocessing code
- `src/features/` - feature engineering utilities
- `src/models/` - training, evaluation, and inference code
- `src/visualization/` - plots and reporting helpers
- `models/` - saved model artifacts
- `reports/figures/` - charts and visuals for reports or portfolio writeups
- `tests/` - automated tests
